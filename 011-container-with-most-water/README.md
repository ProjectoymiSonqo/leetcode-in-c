# 11. Container With Most Water

## 思路

面積由「底 × 高」決定。

一開始從陣列兩端開始，因為此時可以取得最長的底。

接著逐步縮小範圍：

- 容器的高度由左右兩邊較短的一側決定
- 每次縮小範圍後，底一定會變短
- 因此若想得到更大的面積，就必須嘗試提高目前的短板
- 淘汰較短的一邊，保留較長的一邊繼續搜尋
- 每一輪計算面積並記錄最大值

面積：

`area = (right - left) * min(height[left], height[right])`

核心概念：

> 底從最大開始逐漸縮短，淘汰短板，尋找更高的短板來補償底的損失。

## 複雜度

- Time: `O(n)`
- Space: `O(1)`
