# 189. Rotate Array

## 思路

將陣列視為兩個區塊：

```text

[1,2,3,4 | 5,6,7]

            ↑

       numsSize - k
當 k = 3 時，先暫存最後 k 個元素，再將前面的元素往後移，最後把暫存的元素放回前面：
[1,2,3,4 | 5,6,7]

        ↓

[5,6,7 | 1,2,3,4]
k 超過陣列長度

一開始沒有考慮 k > numsSize 的情況。

例如：
旋轉兩次會回到原位，因此真正有效的旋轉次數是：
k = k % numsSize;
所以：
3 % 2 = 1
等價於只旋轉一次。
複雜度

* Time: O(n)
* Space: O(k)
