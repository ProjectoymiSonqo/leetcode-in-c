# 題目

3. Longest Substring Without Repeating Characters

# 問題拆解

維護一個目前合法的字串區間。

區間內不能出現重複字元。

每讀到一個新的字元：

- 檢查它是否已經存在於目前區間。
- 如果沒有，區間可以繼續往右擴張。
- 如果有，將左邊界（checkpoint）移到重複字元的下一格。
- 每次更新目前區間長度，並記錄最大值。

# 解題思路

不是重新開始找。

而是維持一個有效區間。

重複時，只移動左邊界。

# Design Pattern

Sliding Window（滑動視窗）

# 我學到什麼

真正移動的是合法區間，而不是重新搜尋整個字串。
