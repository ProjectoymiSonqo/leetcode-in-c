# 7. Reverse Integer

## 問題拆解

將一個整數的每一位數反轉。

例如：

123 → 321

-123 → -321

120 → 21

---

## 解題思路

一開始先判斷正負號。

如果是負數，先記錄 sign。

接著利用：

- `%10` 取得目前最右邊的一位數
- `/10` 去除目前最右邊的一位數

例如：

```
1520

1520 % 10 = 0
1520 / 10 = 152

152 % 10 = 2
152 / 10 = 15

15 % 10 = 5
15 / 10 = 1

1 % 10 = 1
1 / 10 = 0
```

每取得一個 digit，就將它接到新的整數尾端。

```
new_x = new_x * 10 + digit
```

最後再根據 sign 決定是否加回負號。

---

## 核心機制

每次只處理一位數。

```
digit = x % 10
```

取得最後一位。

```
x = x / 10
```

移除最後一位。

```
new_x = new_x * 10 + digit
```

將新的 digit 接到答案尾端。

---

## Design Pattern（解題模式）

Digit Extraction（逐位拆解）

利用 `%10` 與 `/10` 持續取出最低位。

再利用乘 10 建立新的整數。

## 我學到什麼

整數不像字串，不需要先知道總共有幾位。

只需要不斷取出最後一位即可。

另外這題真正困難的是處理 Integer Overflow。
